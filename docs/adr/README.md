# ADR (Architecture Decision Records)

대안을 저울질한 **아키텍처 결정**을 하나씩 불변 기록. 제품·경제 규칙은 여기 말고 [[2026-07-29-kleague-market-design]](설계 스펙)에.

형식: `template.md` 참고. 파일명 `NNNN-제목.md`. 한 번 채택되면 내용을 바꾸지 않고, 뒤집을 땐 새 ADR로 대체.

단, **결정에 영향이 없는 정정**(오탈자·깨진 링크·존재하지 않는 문헌의 인용)은 허용한다.
결정·근거·대안의 **내용**이 달라지면 정정이 아니라 번복이므로 새 ADR로 대체한다.
