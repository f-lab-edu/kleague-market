# ADR-0007: 선수 상장폐지(delisting) 라이프사이클

- 상태: 채택됨
- 날짜: 2026-08-05

## 맥락 (Context)

선수가 K리그1을 떠나면(이적·은퇴·군입대·K2 이적) 경기·배당이 끊긴다. P2P라 전원이 팔려
하는데 매수가 없어 **가격 폭락이 아니라 유동성 소멸**(거래 자체가 안 되는 얼어붙은 자산)이
생긴다. 선수 풀은 유한하고 이런 이탈은 시즌 내내 발생한다. 이를 어떻게 처리할지 정해야 한다.

## 고려한 대안 (Considered Options)

- **하드 삭제** — 원장·체결·보유가 playerId를 참조하므로 **참조 무결성 붕괴**. 불가.
- **Inactive 플래그** — 거래 불가 자산이 계속 쌓이고, **유동성 소멸 문제 미해결**.
- **상장폐지 라이프사이클**(ACTIVE → DELISTING_PENDING → DELISTED) — 실제 증시처럼
  거래정지 → 최종 정산 → 소각. ← 선택

## 결정 (Decision)

**선수를 상장 자산으로 보고 상장폐지 라이프사이클로 관리한다.**
- `DELISTING_PENDING`: 이탈 확정 후 **거래 N일 유지**(exit 창; 즉시 폐지는 악용 가능) → 이후 거래 정지.
- `DELISTED`: **최종 정산금 지급 → 보유 주식 소각 → 유니버스에서 제거.**
- 정산가 = **조작 내성 참조가**([[0006-이벤트-로그-데이터-캡처|ADR-0006]]의 로그로 계산하는 D8 Ranking Price 재사용).
- **하드 삭제 금지**(soft 상태) — 레코드는 남기고 마켓엔 `tradable=false` + `tradableReason`.

## 근거 (Rationale)

- 유동성 소멸을 **"정산으로 깔끔히 청산"**해 해결 — 모두 같은 기준으로 정산되고 시장이 깨끗.
- **"선수 = 상장 자산"** 컨셉과 부합, Inactive 무덤 회피.
- **참조 무결성 유지**(soft delete) — 과거 원장·체결이 그대로 유효.
- 즉시 폐지는 악용 가능 → **exit window(grace)**로 완화.

## 결과 (Consequences)

- **얻는 것**: 깔끔한 청산, 거래 불가 자산 누적 없음, 도메인 정체성 부합.
- **감수하는 비용**: 라이프사이클 상태·정산 로직. **트리거 감지**(이탈 판정)가 모호 — `/transfers`
  또는 "스쿼드에서 사라짐" 휴리스틱 + **수동 override**.
- **스코프**: 라이프사이클 상태·정산 **정책은 설계 확정**, 자동 감지+정산 **실행은 2차(또는 수동)**.
  MVP는 2024 시즌 활성 선수로 상장.
